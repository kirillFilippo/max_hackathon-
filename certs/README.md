# Сертификаты

Сюда можно положить корневой сертификат, если платформа MAX не проходит проверку
TLS системным хранилищем Node.

Ожидаемое имя файла:

    certs/russian-trusted-root-ca.pem

После появления файла бот сам перезапустит себя с `NODE_EXTRA_CA_CERTS`
(в Docker путь передаётся через `MAX_CA_CERT_PATH=/app/certs/russian-trusted-root-ca.pem`).
Файл добавляется к системным сертификатам, а не заменяет их.

Файла может и не быть: без него бот работает на системных сертификатах и при
ошибке TLS печатает понятную инструкцию. Реальные сертификаты в репозиторий не
коммитим.
